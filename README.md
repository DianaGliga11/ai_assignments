## 📚 Assignments

### 1. 🌸 Iris Dataset – Data Analysis & Classification

The Iris assignment focuses on exploring and analyzing the well-known **Iris flower dataset**.

The dataset contains measurements such as sepal length, sepal width, petal length, and petal width for different Iris species.

The assignment covers:

* Loading and exploring a dataset
* Data preprocessing
* Statistical analysis
* Data visualization
* Feature analysis
* Classification of Iris species
* Evaluating the obtained results

The main goal was to understand the typical workflow of a Machine Learning problem, starting from raw data and ending with a classification model.

**Technologies:** Python, Pandas, NumPy, Matplotlib, Scikit-learn

---

### 2. 🩺 Diabetes Dataset – Machine Learning

This assignment uses the **Diabetes dataset** to explore Machine Learning techniques for predicting a numerical target based on several medical-related features.

The project focuses on:

* Dataset exploration
* Feature and target analysis
* Data preprocessing
* Splitting the dataset into training and testing sets
* Training a Machine Learning model
* Generating predictions
* Evaluating model performance

The assignment provided practical experience with regression problems and with the process of measuring how accurately a model can predict unknown values.

**Technologies:** Python, Pandas, NumPy, Scikit-learn, Matplotlib

---

### 3. 🌳 Random Forest

This assignment focuses on the **Random Forest** Machine Learning algorithm.

Random Forest is an ensemble learning method that combines multiple decision trees to produce a final prediction.

The project explores:

* Training a Random Forest model
* Working with training and testing datasets
* Making predictions
* Evaluating classification performance
* Understanding ensemble learning
* Analyzing the importance of input features

The assignment helped demonstrate how combining several decision trees can produce a robust Machine Learning model.

**Technologies:** Python, Scikit-learn, Pandas, NumPy

---

### 4. 🧠 PyTorch – Neural Networks

This assignment introduces **Deep Learning using PyTorch**.

The project focuses on creating and training neural networks and understanding the main components involved in the training process.

The main concepts include:

* PyTorch tensors
* Dataset preparation
* Neural network architecture
* Layers and activation functions
* Forward propagation
* Loss functions
* Backpropagation

The assignment provided practical experience with the fundamental concepts behind neural networks and Deep Learning.

---

### 5. 🐝 PSO – Particle Swarm Optimization

This assignment explores **Particle Swarm Optimization (PSO)**, a population-based optimization algorithm inspired by the collective behavior of groups such as bird flocks or fish schools.

The algorithm works with a population of candidate solutions called particles. Each particle moves through the search space based on its own experience and the experience of the swarm.

The project covers:

* Initializing a population of particles
* Defining particle positions and velocities
* Evaluating the objective function
* Updating particle velocities
* Updating particle positions
* Tracking the best individual solution
* Tracking the global best solution
* Visualizing the optimization process

The goal was to understand how metaheuristic algorithms can be used to find good solutions to optimization problems.

**Technologies:** Python, NumPy, Matplotlib

---

### 6. 📉 Ackley Function – Optimization

This assignment uses the **Ackley function**, a well-known benchmark function for testing optimization algorithms.

The function has a complex search space with many local minima and a global minimum, making it useful for evaluating optimization techniques.

The assignment focuses on:

* Defining the Ackley objective function
* Visualizing the function
* Exploring the search space
* Applying optimization techniques
* Evaluating candidate solutions
* Analyzing the convergence toward the global optimum

The assignment was used to understand the challenges of numerical optimization and the behavior of optimization algorithms in complex search spaces.

**Technologies:** Python, NumPy, Matplotlib

## ▶️ How to Run

The assignments were developed in **Google Colab**.

To run a notebook:

1. Open the desired `.py` file.
2. Upload it to Google Colab or open it directly from GitHub.
3. Make sure the required Python libraries are installed.
4. Run the notebook cells sequentially.

Most dependencies can be installed using:

```bash
pip install numpy pandas matplotlib scikit-learn torch
```
